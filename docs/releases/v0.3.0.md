# drive2sim v0.3.0

Bản phát hành phần mềm: lái thử cảnh dựng lại trong CARLA, tinh chỉnh Instant NuRec trên nhiều GPU,
tải và đẩy file kết quả lên Google Drive ngay từ Studio.

## Cài

```bash
npx github:thaianh20021/drive2sim            # Node.js 18+: cài, rồi `... start` để bật Studio
bash envs/install.sh                         # Linux, macOS (từ gói nén hoặc bản clone)
powershell -ExecutionPolicy Bypass -File envs\install.ps1   # Windows
```

Chi tiết: `docs/install.md`. Linux có GPU NVIDIA cài đủ để train trên máy; macOS, Windows và
Linux không GPU cài Studio + CLI, chạy run trên Kaggle, Colab. Đã cài v0.2.0 thì chạy lại lệnh cài:
venv được dùng lại, chỉ cập nhật mã nguồn và gói.

| File | Dùng cho |
|---|---|
| `drive2sim-v0.3.0-linux.tar.gz` | Linux: mã nguồn kèm nội dung submodule (4D-Humans, gsplat-geer bản fork), cài đủ không cần git |
| `drive2sim-v0.3.0-macos.tar.gz` | macOS: mã nguồn (chế độ Studio) |
| `drive2sim-v0.3.0-windows.zip` | Windows: mã nguồn (chế độ Studio), chạy `envs\install.ps1` |

## Có gì mới

- **CARLA**: nối với CARLA 1.0 và server render NuRec; trang **Lái thử** có tốc độ khung hình, tải
  GPU; xe và người lấy từ box 3D của cảnh, có nút bật tắt.
- **Instant NuRec**: tinh chỉnh sau feed-forward (`train.nurec_refine`), chia theo đoạn đường cho
  mọi GPU trống; số Gaussian tuỳ chọn hoặc không giới hạn; dựng cả đoạn clip; chọn GPU trống nhất;
  chấm điểm như `eval.standard` kèm PSNR theo vùng; video có hàng ảnh gốc nội suy mượt.
- **Studio**: mục **Tải về** (PLY Gaussian, PLY NuRec, `scene.usdz` cho CARLA, checkpoint, video);
  nút **Đẩy lên Drive** qua phiên Colab đã kết nối Drive; tiến độ run cập nhật trực tiếp; xoá,
  huỷ, tải tiếp dataset và lượt lấy từ Drive; `d2s studio --host`, `--allow-host` để cả nhóm mở
  Studio qua mạng riêng (Tailscale).
- **Cài đặt**: `npx github:thaianh20021/drive2sim start` nhận `--host`, `--allow-host`.
- **Sửa lỗi**: run NuRec xuất PLY qua `export.nurec_ply` và không còn nút xuất preview (cần
  checkpoint 3DGS); `prep.ncore` báo tên gói KITTI-360 còn thiếu; lấy nhiều mục từ Drive gộp vào
  một thư mục.
