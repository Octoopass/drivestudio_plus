# drive2sim v0.4.0

Bản phát hành phần mềm: gộp code của nhóm trên nhánh `drive2sim` (Octoopass/drivestudio_plus PR #2):
approach XSIM (thử nghiệm), dataset PHENIKAA, sửa mặt nạ xe ego trong Studio, cùng mọi tính năng
của v0.3.0.

## Cài

```bash
npx github:thaianh20021/drive2sim            # Node.js 18+: cài, rồi `... start` để bật Studio
bash envs/install.sh                         # Linux, macOS (từ gói nén hoặc bản clone)
powershell -ExecutionPolicy Bypass -File envs\install.ps1   # Windows
```

Chi tiết: `docs/install.md`. Linux có GPU NVIDIA cài đủ để train trên máy; macOS, Windows và
Linux không GPU cài Studio + CLI, chạy run trên Kaggle, Colab. Đã cài bản cũ thì chạy lại lệnh cài:
venv được dùng lại, chỉ cập nhật mã nguồn và gói.

| File | Dùng cho |
|---|---|
| `drive2sim-v0.4.0-linux.tar.gz` | Linux: mã nguồn kèm nội dung submodule (4D-Humans, gsplat-geer bản fork), cài đủ không cần git |
| `drive2sim-v0.4.0-macos.tar.gz` | macOS: mã nguồn (chế độ Studio) |
| `drive2sim-v0.4.0-windows.zip` | Windows: mã nguồn (chế độ Studio), chạy `envs\install.ps1` |

## Có gì mới so với v0.3.0

- **XSIM** (thử nghiệm): train trong venv riêng (`envs/install_xsim.sh`, có nút cài trong Studio),
  checkpoint giữa các lượt, dùng chung dữ liệu cảnh với các approach khác, chấm điểm như
  `eval.standard`, video render và ground truth trong Studio.
- **PHENIKAA**: bộ chuyển dữ liệu, cấu hình 1 đến 10 camera, dựng SMPL từ camera pinhole. Đọc LiDAR
  `.laz` cần `laspy[lazrs]`: có trong môi trường chính (chế độ full) và mục **laspy (LiDAR
  PHENIKAA)** mới ở trang Thư viện.
- **Mặt nạ xe ego**: sửa trong Studio; mỗi run lưu bản mặt nạ đã dùng để chạy lại cho giống.
- **Approach**: nhãn cách xử lý vật chuyển động (box 3D, theo thời gian, tĩnh, tuỳ chọn); approach
  cần box bị làm mờ khi cảnh không có box.
- **Sửa lỗi**: Kaggle tìm dataset SMPL theo tài khoản đã đăng nhập, run lỗi vẫn kết thúc notebook,
  đọc lại `kaggle.json` trước khi đánh dấu đã kéo kết quả; camera của NuRec khi chấm điểm có mặt nạ.

## Kiểm chứng

Bộ test `tests`: 1035 passed, 3 failed (Python 3.10, máy lab có GPU). 3 test lỗi ở
`test_bezier_nodes.py` (BezierGS) đã lỗi trên nhánh `drive2sim` trước khi gộp. Mục Thư viện
PHENIKAA cài thật trên máy lab (numpy, OpenCV giữ nguyên). Bộ cài: xem bảng "Đã kiểm tra" trong
`docs/install.md`. Chưa kiểm tra: train XSIM, ingest một chuỗi PHENIKAA thật, macOS, bộ cài Linux
chế độ full chạy trọn từ máy trắng.
