# drive2sim v0.2.0

Bản phát hành phần mềm: Studio có đủ tính năng của Fisheye Fusion Lab, cài bằng một lệnh trên
Linux, macOS, Windows và máy chủ không màn hình.

## Cài

```bash
npx github:thaianh20021/drive2sim            # Node.js 18+: cài, rồi `... start` để bật Studio
bash envs/install.sh                         # Linux, macOS (từ gói nén hoặc bản clone)
powershell -ExecutionPolicy Bypass -File envs\install.ps1   # Windows
```

Chi tiết: `docs/install.md`. Linux có GPU NVIDIA cài đủ để train trên máy; macOS, Windows và
Linux không GPU cài Studio + CLI, chạy run trên Kaggle, Colab.

| File | Dùng cho |
|---|---|
| `drive2sim-v0.2.0-linux.tar.gz` | Linux: mã nguồn kèm nội dung submodule (4D-Humans, gsplat-geer bản fork), cài đủ không cần git |
| `drive2sim-v0.2.0-macos.tar.gz` | macOS: mã nguồn (chế độ Studio) |
| `drive2sim-v0.2.0-windows.zip` | Windows: mã nguồn (chế độ Studio), chạy `envs\install.ps1` |

## Có gì mới

- **Cài đặt**: `envs/install.sh`, `envs/install.ps1`, lệnh Node `npx github:thaianh20021/drive2sim`
  (`install`, `start`, `stop`, `status`); nút **Cài tất cả** ở trang Thư viện và
  `d2s libraries install --all`. Lệnh pip của bảng thư viện không đổi phiên bản gói đã có.
- **Studio (từ Fisheye Fusion Lab)**: tải dữ liệu gốc từ máy tính, từ Google Drive qua phiên Colab
  (nhận dạng dataset khi duyệt, tải một chuỗi KITTI-360); cài môi trường trên máy từ Studio; Trợ lý
  (Anthropic, OpenAI, Gemini, OpenRouter, endpoint tương thích OpenAI); thời gian còn lại của stage;
  trang Thư viện; ghép video hai run; toàn cảnh 360° và LiDAR chồng ảnh ở trang Cảnh; tài khoản
  Google cho Colab.
- **Approach**: Instant NuRec (feed-forward của NVIDIA, cảnh KITTI-360) có video đi dọc đoạn đường
  theo tốc độ gốc; PVG, DeformableGS; OmniRe nhiều camera.
- **Dữ liệu**: cảnh KITTI-360 có box 3D từ metadata ROSA khi không có `data_3d_bboxes` (đọc pickle
  chỉ cho mảng numpy), nên Street Gaussians, OmniRe chạy được trên KITTI-360.
- **Sửa lỗi**: ô môi trường ở Chạy mới chỉ đòi file SMPL khi run thật sự dựng người; tải một chuỗi
  KITTI-360 kèm metadata ROSA mà NuRec cần.
