# drive2sim v0.1.0

Bản phát hành phần mềm. Gói kết quả được chia sẻ riêng qua Google Drive.

## Tiếng Việt

Tool gồm CLI và Studio cho ingest, chọn split, chạy tái dựng, so sánh metric và xem/xuất cảnh.
OmniRe và Street Gaussians dùng chung pipeline DriveStudio với renderer 3DGS, 3DGUT, 3DGEER.
FastGS, Faster-GS và MCMC là lựa chọn riêng, có ràng buộc tổ hợp trong approach.

Thay đổi trong lượt hoàn thiện này:

- Ingest gợi ý thư mục dataset đúng khi truyền nhầm thư mục cha/con. nuScenes thiếu sweeps
  được báo trước; ingest chỉ keyframe với `--interpolate-n 0` vẫn dùng được.
- Run local thiếu môi trường dừng trước khi tạo run, kèm hướng dẫn cài hoặc dùng Kaggle/Colab.
- OmniRe tự bỏ stage SMPL nếu box xác nhận split không có người. Nhãn thiếu/hỏng giữ trạng
  thái chưa biết, không tự bỏ người. Manifest cũ có thể được bổ sung thông tin trong bộ nhớ.
- `d2s pack RUN_ID... --output results.tar [--dry-run]` gói đủ checkpoint, cảnh và cache được
  tham chiếu. Gói có README hai ngôn ngữ và `pack.json` chứa SHA-256. View tạm được dựng lại;
  symlink còn lại chuyển thành tương đối. Không ghi đè file đích, không gói run đang chạy.
- GPU viewer báo thiếu mô hình SMPL với config có người. Đã sửa NaN màu SH khi camera trùng điểm tạm của người vắng mặt; hướng nhìn suy biến dùng một vector đơn vị, opacity vẫn bằng 0. README gói giải thích riêng checkpoint
  chỉ chứa model và checkpoint khôi phục optimizer.

## English

Software release. The results archive is shared separately through Google Drive.

drive2sim provides a CLI and Studio for ingestion, split selection, reconstruction, comparison,
viewing and export. OmniRe and Street Gaussians share the DriveStudio pipeline and support
3DGS, 3DGUT and 3DGEER renderers. Optional acceleration and densification settings have explicit
compatibility constraints.

This handoff adds actionable dataset/environment errors, split-aware SMPL selection, a complete
`d2s pack` archive with checkpoints and referenced caches, portable symlinks, SHA-256 inventory,
and an SMPL body-model check for GPU viewing. Missing or corrupt person annotations remain
unknown and do not cause automatic removal of people.

Both Python 3.12 and Python 3.9 suites completed with 439 passed and 14 skipped. Ruff, whitespace
checks, generated TypeScript and the frontend build passed. A clean light installation on
Python 3.13, wheel installation outside the source tree and basic Studio HTTP/API checks passed.
Archive tests cover extraction, hashes, checkpoints, cache dependencies and links after removal
of the original workdir. The real 11-run archive is 16,097,525,760 bytes and all 15,708 file hashes
matched after extraction. Studio read one scene, 11 runs and 11 comparison rows from that copy.

These checks do not establish a clean CUDA installation, GPU training regression acceptance or
full interactive browser acceptance. The ingest warning flow was exercised in the browser. A real GPU frame from the unpacked archive rendered after fixing zero-length SMPL view directions; an ordinary frame matched the pre-fix image exactly (270,000 uint8 color values). This used the existing GPU environment. No new training was started. Existing measurements and pending
experiments are in `docs/experiments/run_plan.md`; MCMC quality remains experimental. The required SMPL body model is included in handoff archives under smpl_models/. Credentials and raw datasets are excluded.
No archive has been uploaded to an external service.

## Tải và sử dụng / Download and use

Tải wheel từ mục Assets của Release và lấy `results-nuscenes-11runs.tar` từ link
Google Drive do người gửi cung cấp. Cài wheel, giải nén tar vào thư mục trống rồi
làm theo README bên trong. `README_HANDOFF.md` có hướng dẫn cài và giải nén nếu cần;
`SHA256SUMS` là file kiểm tra tùy chọn. Không cần tải `verified-workdir/`; đó là bản
giải nén dùng để kiểm chứng.

Download the wheel from the release assets and obtain the results archive from the
sender's Google Drive link. Install the wheel, extract the archive into an empty
directory and follow the README inside. README_HANDOFF.md provides optional setup
instructions; SHA256SUMS provides optional file verification.

The software wheel excludes raw datasets, credentials, checkpoints and SMPL model files.
The separately shared results archive contains the required SMPL model, which retains
its own license terms and is not uploaded as a GitHub release asset.
